# StudentArtifact Contract v0

## Purpose

StudentArtifact is the HF-shaped Level 0/1 output box produced by the burn. It
contains the selected student config, vocab contract, runtime metadata,
checkpoint or params, burn/eval/export reports, and validation evidence.

P116 defines and validates the box. It does not train, export a new production
model, add full Hugging Face integration, or run the real burn.

## HF-Shaped Level 0/1 Boundary

StudentArtifact is HF-shaped, not HF-native. It provides stable local files and
loader-oriented metadata, but it does not require `transformers`,
`PreTrainedModel`, generation, or official lm_eval integration.

Level 0/1 means:

- predictable local artifact layout
- explicit student config
- explicit vocab contract
- explicit checkpoint/params reference
- explicit runtime metadata
- explicit reports and claims not made
- validation before result claims

## Layout

Preferred layout:

```text
student_artifact/
  student_config.json
  vocab_contract.json
  runtime_metadata.json
  checkpoint/
    checkpoint.json
    params.npz
  burn_report.json
  eval_report.json
  export_report.json
  validation_report.json
```

The validator also accepts a top-level `params.npz` or `model.safetensors`
where appropriate. `validation_report.json` may be generated by validation and
is not required to exist before validation starts.

## Student Config

`student_config.json` fields:

```text
artifact_type: student_artifact
artifact_version: 0
architecture_id
student_family
vocab_size
vocab_contract_path
runtime
reference_runtime_default
pallas_opt_in
target_type
checkpoint_format
forward_input_shape
forward_output_shape
created_from_teacher_textbook
claims_not_made
```

For P117, `architecture_id` must be `current_qrwkv`, `student_family` must be
RWKV-family, and vocab must come from the validated TeacherTextbook.

## Runtime Metadata

`runtime_metadata.json` fields:

```text
runtime
jax_version: optional
jaxlib_version: optional
platform: optional
devices: optional
pallas_enabled
reference_runtime_default
```

For P117, reference runtime remains default and Pallas remains opt-in only.

## Validation Report

`validation_report.json` fields:

```text
artifact_type
artifact_version
status
checks
blockers
warnings
student_config_ok
vocab_contract_ok
checkpoint_ok
burn_report_ok
eval_report_ok
export_report_ok
runtime_metadata_ok
validation_report_ok
architecture_ok
vocab_matches_teacher_textbook
pallas_not_default
claims_not_made
```

## Validation Rules

The P116 validator checks:

- `student_config.json` exists and contains required fields
- `vocab_contract.json` exists and is a JSON object
- `runtime_metadata.json` exists and contains required fields
- checkpoint or params exists
- `burn_report.json`, `eval_report.json`, and `export_report.json` exist
- `architecture_id` matches the expected P116/P117 architecture
- reference runtime default and Pallas opt-in policy are preserved
- claims not made are present
- when a TeacherTextbook path is provided, the student vocab contract matches
  the TeacherTextbook vocab contract

Commands:

```bash
python scripts/validate_student_artifact.py \
  --path artifacts/p117_student_burn/student_artifact \
  --teacher-textbook artifacts/p117_teacher_textbook \
  --write-report
```

## What Full HF-Native Still Means Later

Full HF-native support would mean a maintained `transformers` integration,
likely including a config/model class, `PreTrainedModel`-style loading,
generation semantics, and official evaluation-tool compatibility. That remains
future work and is not required by StudentArtifact v0 or P117.

## Claims Not Made

StudentArtifact v0 does not claim:

- full HF-native model support
- `PreTrainedModel` support
- generation support
- official lm_eval support
- model quality
- Qwen parity
- KVM, FLA, or Vocab C evidence
- tokenizer remapping
- Pallas default or production readiness
- universal recurrent architecture success
